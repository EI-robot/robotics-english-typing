# 工程英语打字教程

这是为有大学英语六级经历、从事机器人与运动控制的学习者设计的四周教程。重点练习技术阅读中的高频词、常用搭配、工程表达与灵巧操作术语。每天安排 20 至 30 分钟，包含 20 天新词学习与 8 天复习应用，共 100 个目标词或短语。

## 开始学习

直接用浏览器打开 `dist/index.html` 即可使用，无需安装依赖。保持文件夹中的 CSS 和 JavaScript 文件在原位置。浏览器若限制本地文件存储，使用下方的固定本地网址。

已经安装 Node.js 时，也可以在此目录执行：

```powershell
npm start
```

然后打开 <http://127.0.0.1:4173>。使用同一个浏览器和网址，进度才会留在同一个存储空间。关闭服务器后，本地网址暂时无法访问；再次运行即可继续。直接打开文件与通过本地网址学习是两个独立的进度空间，可以导出和导入进度进行转移。

## 每天怎么练

1. 用 5 分钟复习到期词，先回忆再看提示。
2. 用 7 分钟学习最多 5 个目标词与搭配。
3. 用 7 分钟输入例句并理解含义，改写其中一两句。
4. 用 4 分钟遮住英文，从中文回忆目标词。
5. 用 2 分钟写自己的表达。建议写 30 至 60 词，时间不足时至少写 20 词。

这是默认 25 分钟分配。页面可选 20、25 或 30 分钟，并随时保存返回。题目提前打完时，剩余时间用于朗读、改写和自检；不需要再开一课。写作只统计词数，不自动判断语法、词汇用法或技术结论。

前两天如果觉得目标词熟悉，重点练习搭配和自己的表达；无提示回忆率低于 60% 时，可以先练前 3 个词，保存后下次完成剩余内容。课程序号表示学习顺序，不要求连续 28 个自然日完成。

## 四周内容

| 周次 | 主题 | 示例词汇 |
| --- | --- | --- |
| 第 1 周 | 技术阅读、需求、论证和评估 | clarify, ambiguous, constraint, trade-off, validate |
| 第 2 周 | 调试、集成和工程取舍 | reproduce, discrepancy, robust, overhead, bottleneck |
| 第 3 周 | 控制、轨迹和灵巧操作 | disturbance, saturation, reference frame, impedance, dexterity |
| 第 4 周 | 论文阅读、实验与研究表达 | ablation, generalization, formulation, compensate, quantify |

每周最后两天不加新词，使用已练词汇回忆与写作。不要把课程完成率、打字准确率直接当作词汇掌握率。

## 复习与保存

看着英文照打不提升记忆等级。无提示回忆第一次答对后，复习间隔依次为 1、3、7、14、30 天，按每次成功回忆的日期递推。同一天重复成功不会继续拉长间隔。答错或使用提示后，第二天再练。

新词课优先复习最多 10 个到期词；超过 20 个到期词时建议先做最多 15 个复习。可在首页点击“只复习到期词”，不增加新词、不推进课程天数。漏学时继续下一课即可。

进度存放在当前浏览器的 localStorage 中，包括当前题目、输入、写作、复习日期与完成情况。请只开一个标签页学习，避免多页同时覆盖。每周导出一次 JSON 备份；导入会替换当前进度，页面会先确认。更换设备或清理浏览数据不会自动保留进度。

发音使用设备上的浏览器语音，需要可用的英语语音。课程本身不请求远程接口；浏览器的具体语音是否依赖网络由设备决定。未安装英语语音时，打字练习仍可正常完成。

## 学习检验

每周自测时，不看例句，选 5 个词写 50 至 80 词，再朗读 60 秒。检查搭配是否自然、论证是否保留条件、句子的意思是否能解释。两次相隔至少 3 天都能无提示回忆，并能在新句子中使用，可以暂记为熟悉。

本课程的 100 项中包含熟词与短语，不承诺词汇量净增加 100，也不把六级成绩换算为当前 CEFR 等级。所有工程例句均是原创的假想情境，并非真实实验结论。

## 维护与验证

界面与课程使用原生 HTML、CSS 和 JavaScript，没有运行时第三方依赖。`dist/course.js` 是课程内容；`dist/engine.js` 管理复习与存档校验；`dist/app.js` 管理学习交互。

开发验证：

```powershell
npm install
npm test
```

浏览器测试使用 Playwright，在当前 Windows 环境优先使用已安装的 Chrome。其他环境需要可用的 Playwright Chromium。测试使用独立端口 4174 和临时浏览器配置，不操作真实学习进度。

验证覆盖课程完整性、回忆调度、同日重复回忆、完整一课、提示与错答、刷新续学、暂停、词汇检索、导入导出、本地文件打开及手机布局。实际长期记忆效果需要持续学习后检验；发音音质取决于设备。
